# JetDev

JetDev is a recruitment-focused portfolio and online resume for Jiahang "Jet" Sun, a Melbourne-based full-stack software engineer with one year of experience.

The single-page website introduces Jet's selected projects, professional experience, technical skills, education and contact details. It also provides direct access to the latest Resume PDF, GitHub and LinkedIn.

The interface uses responsive light and dark themes, defaults to the visitor's system preference, and provides a persistent manual theme choice. It retains restrained motion and a shared global token system. Public content is written in Australian English and is based on verified Resume information.

## Technology

- Vue 3
- Vue Router
- Vite
- Tailwind CSS 4
- VueUse
- OGL
